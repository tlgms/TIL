# npm run format

`npm run format`은 작성한 코드를 정해진 규칙에 맞춰 보기 좋게 들여쓰기, 줄바꿈, 세미콜론 정돈 등을 자동으로 정리가 되도록 실행해 주는 명령어이다.

## 주요 기능

- 자동 들여쓰기 & 줄바꿈: 엉망으로 꼬여 있는 코드를 보기 편하게 일정한 간격으로 맞춰줌.

- 따옴표 및 세미콜론 통일: 작은따옴표(`'`)나 큰따옴표(`"`), 문장 끝 세미콜론(`;`) 누락 등을 프로젝트 규칙에 맞춰 하나로 통일해 줌.

- 협업 시 스타일 통일: 여러 명이 같이 작업할 때 작성자마다 다른 코드 스타일을 하나로 합쳐주는 역할을 함.

## 참고

이 명령어는 프로젝트의 `package.json` 파일 안에 `format`이라는 이름의 스크립트(Script)가 미리 등록되어 있어야 작동합니다.

```json
// package.json

"scripts": {
  "format": "prettier --write ."
}
```

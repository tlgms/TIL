# 다양한 출력 형태

### 1. 공백을 확보하기 위한 서식 문자

- 정수형 표현 : %( 공간 크기 )d

- 실수형 표현 : %( 공간 크기 )f

- 문자형 표현 : %( 공간 크기 )c

- 문자열형 표현 : %( 공간 크기 )s

- 공간 크기에 만큼의 공백을 확보하고 오른쪽으로 정렬되어 출력한다.

- 지정한 자리보다 출력 값의 자리가 더 큰 자료는 오버되어 출력된다.

- 실습 예제
```c
// 예제 1
#include<stdio.h>
int main()
{
	printf("%5d\n", 330);
	printf("%5s\n", "abcd");
	return 0;
}
```

### 2. 소수점 n째 자리까지 출력하기 위한 형식

- %.2f  : 전체 자릿수는 실제대로 출력하고 소수점 이하는 소수 3자리에서 반올림하여 두 번째 자리까지 출력한다.

- %6.2f : 6은 소수점을 포함한 전체 자릿수, 2는 소수점 이하 자릿수를 나타낸다.
  1. 1. 23
![image](../assets/e962cdd741ac824e963b01b0905b76ee.png)
  1. 123. 23
![image](../assets/18a2cdd741ac828abe2f817fae2cefb9.png)
  1. 100
![image](../assets/b3e2cdd741ac8305977b0149f774006f.png)
  1. 0.235
![image](../assets/8002cdd741ac834a87200116d6ac46cf.png)

- %06.2f는 앞에 빈 공간은 0으로 채워진다.

+관련 문제 : 야드(yard)와 인치(inch)를 cm로 변환하여 소수 첫째 자리까지 출력하는 프로그램을 작성하시오.
```c
#define _CRT_SECURE_NO_WARNINGS
#include<stdio.h>
int main()
{
	float yard, inch;
	printf("yard 값을 입력하세요. : ");
	// yard값 입력
	// inch 값을 입력하세요. : 출력
	// inch값 입력

	// yard값을 cm로 변환하여 소수점 첫째 자리까지 출력(1yard = 91.44cm)
	// inch값을 cm로 변환하여 소수점 첫째 자리까지 출력(1inch = 2.54cm)

	return 0;
}
```

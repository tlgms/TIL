# CORS 문제 해결: 프록시 서버 활용법

### 1. 문제의 원인 (SOP)

- **SOP (동일 출처 정책):** 브라우저는 보안을 위해 출처(도메인·프로토콜·포트)가 다른 리소스에 직접 요청을 보내는 것을 기본적으로 차단함.

### 2. 프록시 서버의 해결 원리 (우회 기법)

1. **클라이언트(브라우저) → 프록시 서버**
  - 같은 출처(Same-Origin)인 프록시 서버로 요청 전송 *(SOP 위반 X)*

1. **프록시 서버 → 실제 API 서버**
  - 프록시는 브라우저가 아니므로 제약 없이 외부 서버와 직접 통신

1. **프록시 서버 → 클라이언트(브라우저)**
  - 받은 응답을 브라우저에게 전달
  - 브라우저는 같은 출처로부터 데이터를 받았다고 인식하여 정상 처리

### 3. 주요 장점

- 백엔드 API 서버에서 별도로 `Access-Control-Allow-Origin` 같은 **CORS 헤더를 매번 설정하지 않아도 됨**.

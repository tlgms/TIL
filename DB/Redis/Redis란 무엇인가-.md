# Redis란 무엇인가?

- **정의:** *Remote Dictionary Server*의 약자로, 메모리 기반의 *NoSQL* 데이터베이스입니다.

- **특징:** 빠른 응답 속도, 다양한 자료 구조 지원(스트링, 리스트, 세트 등), *AOF*/*RDB*를 통한 영속성 제공, 고가용성(*Sentinel*, *Cluster*) 지원.

- **주의사항:** 메모리 기반이므로 데이터 용량 제한과 장애 시 데이터 유실 가능성이 있어 대비가 필요합니다.

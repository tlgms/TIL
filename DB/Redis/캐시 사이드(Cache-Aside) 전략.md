# 캐시 사이드(Cache-Aside) 전략

- **정의:** 애플리케이션에서 캐시를 효율적으로 사용하여 데이터베이스(DB)의 부하를 줄이는 패턴입니다.

- **동작 방식:**
  1. 데이터 요청 시 먼저 *Redis*에서 조회합니다.
  1. 캐시에 데이터가 있으면 즉시 반환하며(*Cache Hit*), 없으면 DB에서 조회합니다.
  1. DB에서 조회한 데이터를 *Redis*에 저장하여 다음 요청 시 활용합니다.
  1. 데이터 변경 시 캐시의 해당 데이터를 무효화하여 최신 데이터를 반영하도록 관리합니다.

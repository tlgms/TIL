# 플러시(Flush)

데이터베이스(DB)에서 플러시(Flush)란 메모리 버퍼나 영속성 컨텍스트에 쌓여 있는 변경 내용(등록/수정/삭제 쿼리)을 실제 데이터베이스에 전송하여 동기화하는 작업을 뜻한다.

SQL 쿼리로 만들어 데이터베이스에 보내는 것 커밋과는 전혀 다름

# .toUpperCase(Locale.ROOT);

# 단순 .toUpperCase()의 문제점

그냥 .`toUpperCase()`를 호출하면 사용자의 컴퓨터 언어 환경에 따라 다른 결과가 나올 수 있습니다.
실행 중인 JVM이나 운영체제의 기본 로케일(`Locale.getDefault()`)을 그대로 따르기 때문.

## 대표적인 사례가 터키어 | 문제

- 표준 로케일 (Locale.ROOT / 영어 등):
  - i → I

- 터키어 로케일 (Locale("tr")):
  - i → İ (점 있는 대문자 I)
  - ı → I (점 없는 대문자 I)

# 해결 법

`.toUpperCase(Locale.ROOT);`는중립적인 표준 규칙(Unicode Invariant)으로 변환

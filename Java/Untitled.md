# Untitled

**JVM의 상수 풀(Constant Pool)은 자바 소스 코드에 등장하는 다양한 상수, 리터럴(Literal), 그리고 클래스와 메서드에 대한 참조 정보를 모아두고 관리하는 메모리 영역입니다.** 자바에서 상수 풀은 크게 두 가지 개념으로 나뉩니다. 두 영역은 컴파일 시점과 런타임 시점에서 각각 다르게 동작합니다.

### 1. 클래스 파일 상수 풀 (Class File Constant Pool)

자바 컴파일러(`javac`)가 소스 코드를 `.class` 파일로 컴파일할 때 생성되는 영역입니다.

- **역할:** 클래스 내부에서 사용하는 리터럴 값과 심볼릭 참조(Symbolic Reference)를 보관합니다.

- **보관하는 데이터:**
  - **리터럴(Literal):** 소스 코드에 직접 적은 문자열, 정수, 실수 등 (예: `"Hello"`, `100`, `3.14`)
  - **심볼릭 참조:** 다른 클래스, 메서드, 필드의 이름과 타입 정보 (실제 메모리 주소가 아닌 이름 형태의 참조)

### 2. 런타임 상수 풀 (Runtime Constant Pool)

JVM이 실행될 때, `.class` 파일의 상수 풀 정보가 JVM 메모리의 **메서드 영역(Method Area)**에 로드되면서 생성되는 공간입니다.

- **역할:** 프로그램이 실행되는 동안 필요한 정보를 제공합니다.

- **동적 해석(Dynamic Resolution):** 실행 중에 심볼릭 참조를 JVM의 실제 물리적인 메모리 주소(Direct Reference)로 변경하는 역할을 합니다.

### 💡 참고: 문자열 상수 풀 (String Constant Pool)

일반적으로 자바를 배울 때 자주 접하는 상수 풀은 **문자열 상수 풀(String Constant Pool)**인 경우가 많습니다.

- **위치:** **힙(Heap) 영역**에 존재합니다.

- **목적:** 자바에서 문자열(`String`)은 사용 빈도가 매우 높기 때문에, 메모리를 절약하기 위해 동일한 문자열 리터럴은 단 하나만 생성하고 공유(재사용)하도록 설계된 공간입니다.

```java
String s1 = "Java"; // 문자열 상수 풀에 "Java" 생성 및 참조
String s2 = "Java"; // 이미 풀에 있는 "Java"를 재사용 (s1 == s2는 true)
String s3 = new String("Java"); // 힙 영역에 새로운 객체 생성 (s1 == s3는 false)
```

# 비동기 처리 1 - 콜백 함수

콜백함수는 작업이 끝난 후 실행할 함수이다. 

---

### setTimeout 콜백함수 예시:

```javascript
function hello() {
    console.log("안녕하세요");
}
setTimeout(hello,2000);
```

2초 뒤에 hello 함수 실행됨.

### 실무 예시:

```bash
function saveDB(user,callback) {
    console.log("DB 저장 완료");
    callback(user);
}

function sendEmail(user,callback) {
    console.log("이메일 발송 완료");
    callback(user);
}

function getResult(user) {
    console.log(user.name+" 회원가입 성공");
}

saveDB({ name:"철수" }, function(user) {
    sendEmail(user, function(user) {
        getResult(user);
    });
});
```

# 객체 구조 분해 할당/타입 주석

```typescript
({ value }: { value: unknown }) => { ... }
// ───┬───    ───────┬────────
//    │              └─ 2. 타입 주석 (Type Annotation)
//    └──────────────── 1. 구조 분해 할당 (Destructuring)
```

1. 앞부분 { value } (구조 분해 할당)함수에 넘어오는 객체에서 `value`라는 이름의 프로퍼티만 바로 꺼내어 매개변수(변수)로 사용하겠다는 뜻입니다.

1. 뒷부분 : { value: unknown } (타입 주석)함수로 전달되는 전체 객체가 어떤 형태인지 TypeScript에 알려주는 부분입니다."이 객체는 `value`라는 키를 가지고 있고, 그 값의 타입은 `unknown`(어떤 타입이 올지 모름)이다"라는 의미입니다.
